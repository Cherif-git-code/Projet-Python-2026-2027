# Projet-Python-2026-2027
Repo du groupe d'CHERIF Hugo et de SADJI Benjamin pour le projet de python
Sujet : Dans quelle mesure les conditions météorologiques expliquent-elles la consommation et la production d'électricité en France ?

Nous nous concentrerons sur la période 2021-2025. 
Nous résumerons également la météo de chaque région à celle de sa ville principale (détaillée dans ???). On estime ici que la météo sur la région est à peu près la même que celle de sa ville principale. 

Fichiers : 

Data est le dossier dans lequel est détaillé les data sets utilisés et les transformations opérées sur ces données.

Nous allons utiliser différentes API pour mener à bien ce projet.
Les voicis : 
Les données Données éCO2mix diffusée par L'Open Data Réseau énergie (ODRE) qui décrivent la production et la consommation d'éléctricité en France.
Les données Open Météo qui décrivent la météo dans les détails (température, précipitations, vitesse du vent...) à travers la France.
